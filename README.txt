JARVIS für iPad – erste Demo

Enthalten:
- index.html: Oberfläche, einfache eingebaute Antworten, Sprach-Ein-/Ausgabe
- manifest.json, sw.js, icon.svg: PWA-Dateien für Hosting über HTTPS

Wichtig:
- Diese Version hat NOCH KEINE echte KI-Verbindung.
- Sie sendet keine Sprachdaten an einen KI-Anbieter.
- iPadOS/Safari unterstützt Spracherkennung je nach Version unterschiedlich.
- Für „Zum Home-Bildschirm“ als Web-App muss das Projekt über HTTPS veröffentlicht werden.
- Niemals API-Schlüssel in index.html eintragen. Eine spätere KI-Anbindung braucht einen sicheren Backend-Server.

Start zum Testen:
Öffne index.html in einem Browser. Für die PWA-Installation später über eine HTTPS-Webadresse bereitstellen.
